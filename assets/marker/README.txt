RUFIÁN — IMAGEN DE SEGUIMIENTO

El archivo target.jpg es la imagen proporcionada para detectar el producto.
La web compila esta imagen con el compilador oficial de MindAR en el navegador al pulsar “Activar experiencia AR”. El resultado .mind vive en memoria como Blob URL durante esa sesión; no necesita targets.mind precompilado.

No cambies el nombre o la ruta del archivo sin actualizar index.html. Usa una impresión nítida, plana, bien iluminada y sin reflejos para mejorar el seguimiento.
